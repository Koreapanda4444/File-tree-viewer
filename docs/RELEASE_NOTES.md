# File Tree Viewer 1.0.0

배포 준비용 초안입니다. 정식 릴리스와 태그는 아직 게시하지 않았습니다.

## 주요 변경

- 탐색 중인 폴더의 외부 생성·삭제·이름 변경을 감지하고 자동 갱신합니다.
- 큰 폴더를 백그라운드에서 전체 정렬한 뒤 페이지별로 표시하고, 새로고침 시 탐색 상태를 복원합니다.
- Real·Virtual·Plan 화면과 메뉴·패널을 정리하고 전용 레트로 아이콘을 적용했습니다.
- Real·Virtual·Snapshot 트리를 TXT·Markdown·JSON으로 미리보기·저장·복사합니다.
- 파일 복사 취소, 외부 변경 시 Undo 보호, Plan·동기화의 Windows 파일 핸들 처리를 보강했습니다.
- 한국어·영어와 Light·Dark·System 테마를 제공합니다.
- Python 설치 없이 실행하는 Windows x64 폴더형 포터블 ZIP을 준비했습니다.
- 설정·기록을 프로그램의 `data/`에 보관하고 이전 버전 데이터의 안전한 복사를 지원합니다. 대상 루트의 기존 복구 자료는 보존합니다.

## 배포 파일

- `FileTreeViewer-1.0.0-windows-x64.zip`
- `SHA256SUMS`

ZIP 전체를 풀고 `FileTreeViewer/FileTreeViewer.exe`를 실행하세요. `_internal/`을 함께 보관하고, 업데이트할 때는 기존 `data/`를 보존하세요. ZIP 안에 한·영 실행 안내가 포함됩니다.

## 검증과 제약

소스·GUI·파일 작업·복구·동기화·데이터 이전 검사와 Windows EXE·한글 경로·포터블 이동·ZIP 압축 해제 실행을 배포 빌드에서 검사합니다. 중요한 파일은 별도 백업하고 Plan의 Diff·충돌·변경 목록을 검토한 뒤 적용하세요.

Snapshot은 파일 내용 백업이 아닙니다. 복구에는 대상 루트의 Journal·백업과 모든 참여 드라이브가 필요합니다. 네트워크 저장장치, 실제 정전·장치 분리, 네이티브 탐색기 드래그는 환경별 추가 확인 대상입니다.
